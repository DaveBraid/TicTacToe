# 02 井字棋环境

原文：[强化学习实战：自定义 Gym 环境之井字棋](https://www.cnblogs.com/wsy950409/p/15647914.html)

离线备份：[02-原文备份.html](02-原文备份.html)

## 学习重点

- 棋盘有九格，两人交替落子；行、列、对角线连成三子，或棋盘填满时结束。
- 原文从蓝方视角使用胜 +1、负 -1、平 0 的终局奖励。
- 单个智能体的后继状态要等对手回应后才形成。原项目游戏程序中的 `Game` 类可用于对照棋盘和胜负判断。

## 动手检查

阅读 `TicTacToe Game.py` 中的 `Game.step()` 与 `Game.judgeEnd()`，确认八条获胜线与终局判断。
